# SkyWater 130nm 2-Input AND Gate (RTL-to-GDSII)

This repository contains the physical design implementation of a 2-input AND gate designed using **OpenLane** and the **SkyWater 130nm PDK** (`sky130A`).

## 📌 Project Details
* **Design Name:** `and_gate`
* **Target PDK:** SkyWater 130nm (`sky130_fd_sc_hd`)
* **Core Utilization:** 10%
* **Target Flow:** OpenLane RTL-to-GDSII
